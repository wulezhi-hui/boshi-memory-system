## 2026-08-25 — DSH 自动记忆插件：JS 正则误判中文修复（isTrivial）

**操作：** bug_fix
**文件：** dsh/boshi-auto-memory.mjs
**详情：**
- 症状：DSH 自动记忆插件对纯中文消息（如"定位问题"、"重启了"）不存库，仅含 ASCII 的消息（如"验证bridge调用"）能存
- 根因：`isTrivial` 的过滤正则 `/^[\s\W_]+$/` 中，JS 的 `\W` 默认只匹配 ASCII 单词字符，**汉字全部匹配 `\W`**，导致任何纯中文消息被误判为"纯符号"而过滤
- 修复：改用 Unicode 感知正则 `/^[\s\p{P}\p{S}]+$/u`（`\p{P}` 标点 + `\p{S}` 符号 + `u` 标志），汉字不再误判；"？？"、"..."等纯标点仍正确过滤
- 验证：重启后纯中文消息"自动记忆应该正常工作了"成功入库（id=8244）
- 附带：插件需 `inject: ['subprocess', 'systemPrompt']`（硬依赖，而非 `ctx.get` 软依赖），否则启动时服务未就绪导致 apply 空转
